# Parike · imágenes editoriales aprobadas

La actualización a la marca **Parike** conserva el ID interno estable `encendedor-sarike-butano` para evitar romper los enlaces o la telemetría existentes. El nombre y la descripción públicos son **Parike**.

## Archivos binarios pendientes de adjuntar a esta rama

Subir, sin renombrar, en `assets/products/`:

- `encendedor-parike-ambos-acabados.webp` (1536 × 1024; ambos acabados)
- `encendedor-parike-plata.webp` (768 × 1024; acabado plateado)
- `encendedor-parike-dorado.webp` (768 × 1024; acabado dorado)

Las imágenes proceden de la composición que aprobó el titular, con separación por recorte y compresión WebP de calidad 94. No se modificaron la forma, la textura o los mecanismos de los encendedores.

La primera imagen del producto muestra los dos acabados. Después aparecen las vistas individuales y, por último, la ilustración de ambos modos de llama.

**Antes de publicar:** contrastar la denominación Parike con el fabricante o envase real. La fotografía ilustrativa contiene la inscripción visible «Sarike». No debe interpretarse como evidencia de grabado «Parike», ni retocarse físicamente el producto sin autorización.

No fusionar este PR hasta adjuntar los tres WebP, ejecutar `npm run build:semantic`, y obtener QA en verde. No habilitar checkout ni cambiar el estado de prelanzamiento.
