# DT Semantic Layer V1 — Registro de cambios

- **DT-SC-001:** 12 archivos de conocimiento, seis productos (cinco documentados; encendedor conceptual), claims, fuentes, intentos hipotéticos, validación estricta de referencias y estados.
- **DT-SC-002:** compilador Node.js nativo, catálogo desde fuente única, huella SHA-256 estable, grafo de conocimiento, JSON-LD y 11 recursos para crawlers/LLMO.
- **DT-SC-003:** seis tarjetas estáticas en portada; cinco rutas individuales con HTML accesible sin JS y una guía de comparación. Mantiene modales y galerías con `p.images` como única fuente.
- **DT-SC-004:** contrato de ocho eventos de observabilidad, normalizador de logs local sin persistencia ni verificación falsa por User-Agent.
- **Restricción permanente:** `noindex, nofollow`, `robots.txt` con bloqueo de rastreo; ningún dominio ficticio, precio, Offer, InStock, IndexNow o backend de costos.
- **Pendiente:** alojamiento, dominio, verificación comercial, pruebas de acceso HTTP directo en infraestructura de publicación y métricas reales de búsqueda/crawler.
